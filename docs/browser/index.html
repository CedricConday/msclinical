Confirmed worsening, PIRA and NEDA in your browser

Paste a visit table (EDSS), relapses and MRI activity. The analysis runs in this page with Python (Pyodide) and the open packages msclinical edssplus, msclinical pirma, msclinical neda, msclinical relapses and msclinical cogworse. Nothing is uploaded; the data never leave your machine. Research software, not a medical device.

Dates as YYYY-MM-DD. Relapse ascertainment is assumed to start at each patient's first visit. The rules are in each package's source; open it before relying on a number.
